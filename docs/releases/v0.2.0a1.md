# SQLAero 0.2.0a1

This alpha reconstructs SQLAero as a synchronous MySQL client with a Rust
connection, protocol, parameter binding, buffering and decoding core. It replaces
the old Cython product rather than preserving its API. Existing 0.1 releases
remain available; applications must review their usage before upgrading.

## Included behavior

- Verified TLS and optional explicit Unix-socket transport; UTC session setup,
  maintained charset/collation selection and explicit client/server timeouts.
- `%s` parameter binding, exact built-in scalar inputs and list/tuple structure,
  native SQL escaping, and bounded complete-row INSERT/REPLACE batching.
- Buffered results with lazy tuple materialization, immutable column metadata,
  independent Cursor positions and execution-time decode settings.
- Transaction contexts, one primary propagated error with immutable diagnostic
  snapshots, maintained client/server error-code enums, and explicit outer retry
  that preserves callable typing. No implicit reconnect or SQL replay.
- Typed public interfaces, English property/method documentation, and complete
  dependency notices. Nonfinite float/Decimal inputs become SQL NULL.

The scalar set is None, bool, int, float, Decimal, str, bytes, bytearray, date,
datetime, time and timedelta. Arbitrary subclasses, memoryview, third-party
arrays/tables and named placeholders are outside this first release.

## Distribution and validation

The release workflow requires four macOS arm64 wheels for regular-GIL CPython
3.12, 3.13, 3.14 and 3.15, plus one source distribution. Each actual wheel is
installed and tested against dedicated MySQL 8.4 and 9.7 instances. A wheel is
also rebuilt and tested from the source archive. GitHub and PyPI receive the same
artifact batch only after those jobs pass. Published archive checksums accompany
the GitHub pre-release.

The wheel's macOS 11.0 deployment tag does not assert runtime testing on every
macOS version. Linux, Windows, Intel macOS, free-threaded Python and async I/O
are not validated release targets.

Local pre-release verification of the frozen native implementation passed
399 Python tests against MySQL 8.4.13 / 9.7.4, 53 Rust unit tests, two real
socket tests and a doctest, together with format, Clippy and type checks.
Installation, release-matrix and publication identities are recorded separately;
local performance timings are not attributed to a different CI-built binary.

## Measured improvements and limits

The final combination passed all 480 main and 204 independent protection
scenarios against the initial correct Rust baseline, with no necessary
statistical gaps or credible costs beyond the agreed 5% band. The main run had
229 reliable improvements greater than 5%. It also retained 17 reliable smaller
costs inside the protection band; the independent run had six such costs.

Representative baseline/final medians on macOS arm64 / CPython 3.13.3:

| Operation | Initial baseline | Final | Speed ratio |
| --- | ---: | ---: | ---: |
| Escape 1,000 equal strings | 36.60 μs | 22.75 μs | 1.61× |
| Escape a 10,000-codepoint Unicode string | 34.39 μs | 2.10 μs | 16.39× |
| Bind 1,000 INSERT rows | 205.41 μs | 130.36 μs | 1.58× |
| Bind 1,000 fallback rows | 291.03 μs | 224.45 μs | 1.30× |
| Materialize 10,000 numeric rows | 1.196 ms | 1.031 ms | 1.16× |
| Materialize 10,000 text rows | 1.230 ms | 1.030 ms | 1.19× |

These measure specific complete native operations, not identical improvements
in network or server latency. No unweighted whole-library speed score is used.
The frozen experimental escape still wins 134 of 140 same-SQL-text cases;
the new core wins six. Another 90 cases have different SQL representations or
contracts and are reported separately. The new driver is not claimed to beat
the older specialized escape on every input.

## Recovery

Keep an application's previous environment or lock file before upgrading. The
old distributions and release tags remain intact. For this alpha, roll back by
recreating that previous environment rather than mixing old and new native
modules in a running interpreter.
